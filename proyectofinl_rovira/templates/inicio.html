Endpoints Principales de la API
Método Endpoint Descripción Permiso Requerido
POST /api/auth/login/ Inicio de sesión y entrega de Token JWT Público
POST /api/auth/register/ Auto-registro de usuarios lectores Público
GET /api/auth/me/ Perfil del usuario autenticado Token JWT
GET|POST /api/libros/ CRUD de Libros del catálogo GET: Autenticado | POST: Bibliotecario/Admin
GET|POST /api/autores/ CRUD de Autores GET: Autenticado | POST: Bibliotecario/Admin
GET|POST /api/categorias/ CRUD de Categorías GET: Autenticado | POST: Bibliotecario/Admin
POST /api/prestamos/ Registrar préstamo (valida disponibilidad de stock) Bibliotecario o Admin
POST /api/prestamos/<id>/devolver/ Registrar devolución (repone stock al catálogo) Bibliotecario o Admin
GET /api/prestamos/activos/ Listado de préstamos activos Bibliotecario o Admin
GET /api/prestamos/mis_prestamos/ Préstamos del lector autenticado Lector autenticado
